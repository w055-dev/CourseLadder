# CourseLadder

## Назначение
Программа помогает студентам выбрать учебные дисциплины на семестр, а учебному офису - контролировать лимиты мест и сроки записи.

## Целевая аудитория
- студенты;
- преподаватели;
- сотрудники учебного офиса.

## Предметная область
Организация выбора дисциплин в вузе: студент записывается на поток (дисциплина + преподаватель + семестр) с учетом лимита мест, дедлайна и количества кредитов.

## Основные сущности
- **Студент** - ФИО, группа, курс;
- **Дисциплина** - названия, преподаватель, кредиты(зачетные единицы);
- **Поток** - дисциплина, поток, лимит мест;
- **Запись** - студент, поток, дата.

## Основные функции
- просмотр списка доступных дисциплин;
- запись студента на выбранный поток;
- проверка лимита мест и дедлайна;
- просмотр своих записей.
